# Quatréa — Four Seasons of Fragrance

A premium, multi-page scrollytelling website concept for the fictional perfume house **Quatréa**: four Eaux de Parfum, one for each season (Printemps, Été, Automne, Hiver).

**Live demo:** https://naveedtwg.github.io/quatrea-concept/

- Static HTML/CSS/JS · GSAP + ScrollTrigger · Lenis smooth scroll
- Pinned horizontal season story with palette shifts, text reveals, parallax, curtain page transitions
- Hand-built SVG logo and bottles, animated season particles, reserve modal, custom cursor
- Responsive, respects `prefers-reduced-motion`

Design & development: Naveed Zulfiqar · Fictional brand, concept only.
